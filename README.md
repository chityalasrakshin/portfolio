# Srakshin's Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, work experience, education, and the projects I have built. It is designed to be fast, responsive, and visually appealing.

## 🚀 Features

- **Responsive Design:** Looks great on both desktop and mobile devices.
- **Dark/Light Mode:** Includes a theme toggle so you can view the site in your preferred color scheme.
- **Dynamic Data:** All of my personal information (projects, skills, etc.) is managed cleanly in a central data file.
- **Interactive UI:** Features smooth animations and interactive components.

## 🛠️ Tech Stack

This website was built using modern web development tools:
- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [Magic UI](https://magicui.design/) and [shadcn/ui](https://ui.shadcn.com/)
- **Language:** TypeScript
- **Deployment:** [Vercel](https://vercel.com/)

## 💻 How to Run Locally

If you want to download and run this code on your own computer, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chityalasrakshin/portfolio.git
   ```

2. **Open the folder:**
   ```bash
   cd portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open in Browser:**
   Go to `http://localhost:3000` in your web browser to see the site running locally!

## 📝 Customizing the Data

If you want to use this template for yourself, you can easily change the content! All the text, links, and images are stored in one place.
- Go to `src/data/resume.tsx`
- Edit the `DATA` object with your own information. The website will automatically update!
